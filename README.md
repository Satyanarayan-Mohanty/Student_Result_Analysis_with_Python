# Student Performance Analysis Using Python

## Project Overview
This project analyzes student result using Python to understand the factors affecting students' academic scores. It uses data analysis and visualization to identify performance patterns and trends.

## Objectives
- Analyze students' academic performance.
- Calculate average scores in different subjects.
- Identify high-performing and low-performing students.
- Visualize score distributions and performance trends.
- Understand the factors influencing student performance.

## Technologies Used
- Python
- Pandas
- NumPy
- Matplotlib
- Seaborn
- Jupyter Notebook

## Dataset
The dataset contains student information and academic scores, such as:
- Student demographics
- Study habits
- Attendance 
- Parent Education
- Exam score


## Project Workflow
1. Load the dataset using Pandas.
2. Explore the dataset.
3. Analyze student scores.
4. Calculate subject-wise averages.
5. Visualize performance using charts.
6. Summarize the key findings.

## Key Analysis
- Average marks by subject
- Score distribution
- Comparison of subject performance
- Identification of high and low scores
- Relationship between available student attributes and academic scores
